# ІАД, Лабораторна робота №1: Базові алгоритми класифікації у Scikit-learn

Виконав: ФБ-62мп Мартинюк Іван

Звіт: [`lab1.ipynb`](lab1.ipynb)

Датасет: [RT-IoT2022](https://archive.ics.uci.edu/dataset/942/rt-iot2022) (UCI Machine Learning Repository). Класифікація мережевих потоків IoT-мережі за типом трафіку чи атаки (11 класів після обробки).

Порівнювались kNN, Decision Tree, SVM, Random Forest і AdaBoost. Найкращий результат показав Random Forest (accuracy 0.988, macro F1 0.958).
